A premium WordPress Maintenance Mode plugin with beautiful dynamic templates, client bypass links, and countdown timer with auto-deactivation.

== Description ==

Netfett Maintenance is a modern, lightweight, and extremely secure maintenance mode plugin for WordPress. It lets you display a professional under-construction/maintenance page while you work on your website.

=== Features ===
* **Dynamic templates**: Choose between Nordic Clean (minimal light), Cosmic Dark (glow glassmorphism), and Cyberpunk Neon (glowing retro sci-fi).
* **Bypass links**: Generate secure tokens for clients so they can preview the live site without logging in.
* **Responsive layouts**: Beautifully crafted CSS layouts that look premium on any screen.
* **Auto-deactivation**: Specify an estimated completion time and the plugin will automatically turn off maintenance mode when the countdown ends.
* **Live preview**: Admins can preview their selected template live via a preview button in the settings.
* **Translation-ready**: Fully translatable labels and texts.

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory, or install the plugin directly through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Use the 'Netfett Maintenance' settings menu to configure your maintenance page.
