A modern, lightweight, and feature-rich WordPress maintenance mode plugin featuring dynamic templates, secure client bypass links, countdown timers, and automatic deactivation.

---

## Installation

### Recommended: Direct Plugin Download
1. Download the latest release package: [**Download netfett-maintenance.zip**](https://github.com/NetFett/netfett-maintenance/releases/latest/download/netfett-maintenance.zip)
2. In your WordPress admin dashboard, navigate to **Plugins > Add New > Upload Plugin**.
3. Select `netfett-maintenance.zip` and click **Install Now**.
4. Activate the plugin.

### Alternative: Git Clone
```bash
cd wp-content/plugins/
git clone https://github.com/NetFett/netfett-maintenance.git netfett-maintenance
```

## Features

* **3 Built-in Design Templates:**
  * **Nordic Clean:** Minimalist light aesthetic with clean modern typography.
  * **Cosmic Dark:** Futuristic glassmorphism with floating animated gradient glow effects.
  * **Cyberpunk Neon:** High-contrast retro sci-fi look with glowing neon accents.
* **Secure Client Bypass Links:** Generate secret URL tokens allowing clients, stakeholders, and testers to preview the live website without needing an admin account.
* **Countdown Timer & Auto-Deactivation:** Set an estimated launch date/time. The countdown displays live for visitors and automatically turns off maintenance mode when the timer hits zero.
* **Live Admin Preview:** Instant preview of your chosen design template right from the WordPress admin dashboard.
* **100% Mobile Responsive:** Handcrafted CSS layouts that look great on desktops, tablets, and phones.
* **Translation Ready:** Fully localized and ready for any language.
* **Automatic Updates:** Built-in update checker directly connected to GitHub Releases.
