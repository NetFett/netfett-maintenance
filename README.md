A modern, lightweight, and feature-rich WordPress maintenance mode plugin featuring gorgeous dynamic templates, secure client bypass links, countdown timers, and automatic deactivation.

---

## ✨ Highlights & Features

* 🎨 **3 Built-in Modern Design Templates:**
  * **Nordic Clean:** Minimalist light aesthetic with clean modern typography.
  * **Cosmic Dark:** Futuristic glassmorphism with floating animated gradient glow effects.
  * **Cyberpunk Neon:** High-contrast retro sci-fi look with glowing neon accents.
* 🔑 **Secure Client Bypass Links:** Generate secret URL tokens allowing clients, stakeholders, and testers to preview the live website without needing an admin account.
* ⏳ **Countdown Timer & Auto-Deactivation:** Set an estimated launch date/time. The countdown displays live for visitors and automatically turns off maintenance mode when the timer hits zero.
* 👁️ **Live Admin Preview:** Instant preview of your chosen design template right from the WordPress admin dashboard.
* 📱 **100% Mobile Responsive:** Handcrafted CSS layouts that look stunning on desktops, tablets, and phones.
* 🌐 **Translation Ready:** Fully localized and ready for any language.

---

## 📋 Requirements

* WordPress 6.0 or higher
* PHP 7.4 or higher (fully compatible with PHP 8.0, 8.1, 8.2, and 8.3)

---

## 🚀 Installation & Usage

1. Download or clone this repository:
   ```bash
   git clone https://github.com/NetFett/netfett-maintenance.git
   ```
2. Upload the `netfett-maintenance` folder to your `/wp-content/plugins/` directory (or download as ZIP and upload via WordPress admin).
3. Activate the plugin through the **Plugins** screen in WordPress.
4. Go to **Netfett Maintenance** in your WordPress admin menu to configure your maintenance page, choose your template, and activate maintenance mode.
